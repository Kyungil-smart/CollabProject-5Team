# 웅냥 게임즈 : 비밀 출근 중입니다.

## 게임 플레이 방법

### 조작 방법
- 터치로 이동, 대화 및 상호작용
- 터치 슬라이드로 카메라 조작
- 핀치 제스쳐로 카메라 줌인, 아웃

### 게임의 흐름
1. 기획, 개발, 아트 직군의 직원을 채용해 회사의 인력을 구성
2. 게임 규모를 선택하고 프로젝트에 참여할 직원을 배치
3. 일일 퀘스트를 통한 업무 수행 및 직원과 대화를 통해 직원의 컨디션을 조절
4. 직원들이 제출한 보고서를 비교하고 프로젝트의 방향성을 결정
5. 게임 출시 결과로 수익을 얻고 회사를 성장
