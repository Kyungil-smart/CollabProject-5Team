# 플레이어
- `HUDPresente.cs`의 `OnWorkStartClicked()`함수에서 '업무 시작' 버튼을 누르면 임시로 '업무 완료' 상태였던 것을 플레이어의 자리 책상으로 이동하는 로직으로 변경
- 기획 변경으로 인해 플레이어가 자리로 가면 업무 시작 버튼이 활성화 되던 것을 말풍선을 터치하면 자동으로 자신의 자리로 가서 업무시작되는 것으로 변경이 되어 `DeskInteract.cs`의 `OnTriggerEnter`,`OnTriggerExit`대신 `OnClickWorkButton()`함수내에 지정된 프리팹의 위치로 이동하도록 변경

# NPC
1. `INPCState.cs`를 인터페이스로 만들어 상태 패턴 세팅
   - `Enter()`: 상태 진입 시 초기 설정(애니메이션, 에이전트 활성 등)
   - `Update()`: 상태 유지 시 로직 실행 (도착 체크 등)
   - `Exit()`: 상태 종료 시 정리
2. `NPCController.cs`에서 상태들을 제어 `_currentState`변수로 NPC가 어떤 상태지인지에 따라 행동할 수 있도록함
3. `NPCMove.cs`에서 `INPCState.cs`를 구현해
   - `Enter()`: NavMesh Agent를 활성화해 이동시키면서 걷는 애니메이션 재생
   - `Update()`: 자신의 자리에 도착하면 `NPCWork` 상태로 변경
   - `Exit()`: 이동이 끝나면 애니메이션 종료
4. `NPCWork.cs`
   - `Enter()`: 지터링 방지를 위해 업무상태시작 시 NavMeshAgent를 종료하고 NPC의 위치를 의자의 `SitPoint`로 이동시킴
5. `NPCLeave`
   - `Enter()`: NPC Spawn위치로 NPC를 이동 시킴
   - `Update()`: 이동완료되면 비활성화
