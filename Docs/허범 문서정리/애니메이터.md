# 애니메이터 설정

## 애니메이션에 관해 기획서는 아직 없는 것으로 아는데 현시점에서 필요하다 싶은 것 넣어봤습니다.

### Animator Controller
  - Player: 기본상태는 Idle05
  - StandingNPC: 서있는 NPC
  - SittingNPC: 앉아있는 NPC

- Parameters
  - Speed(float): 이동할 때
  - Greet(trigger): NPC와 대화 시작 시 인사
  - IsWorkDone(trigger): 업무 완료 됐을 때 기뻐함
  - IsInteraction(bool): 대화중 모션(추후 확장용)

### 플레이어
  1. 걷기(Walk): 걸을 때
    - Transition
      - Idle -> Walk (Has Exit Time 해제), Conditions: [Speed, Greater, 0.1]
      - Walk -> Idle (Has Exit Time 해제), Conditions: [Speed, Less, 0.1]
  
    - 구동방식
      - `PlayerMove.cs`-> `UpdateAnimation()`에서 NavMeshAgent의 속도를 Animator parameters Speed에 속도를 전달
  
  2. 기뻐함(Victory): 업무 완료 시
    - Transition: 
      - Idle -> Victory (Has Exit Time 해제), Conditions: [IsWorkDone]
      - Victory -> Idle (Has Exit Time 체크)
  
    - 구동방식
       - `PlayerMove.cs` -> `CompleteWork`가 실행되면, 
         GameManager에 자동 주입된 플레이어를 찾아 `player.WorkCompleteAnim()`을 호출
       - `PlayerMove.cs` -> `WorkCompleteAnim()` 내부에서 애니메이터의 IsWorkDone 트리거로 재생

### NPC
  1. 인사(HI): 플레이어가 NPC에게 말을 걸었을 때
    - Transition
      - Idle -> Hi (Has Exit Time 해제), Conditions: Greet
      - Hi -> Idle (Has Exit Time 체크)
  
    - 구동방식
      - 플레이어가 레이캐스트로 NPC를 타겟팅 후 상호작용 범위내에 있으면 
        `PlayerMove.cs` -> `TriggerInteraction()`발동
      - `NPCInteract.cs` -> `OnInteract()`에서 NPC인사 실행되며 자기 자신의 애니메이터에 Greet트리거 실행
