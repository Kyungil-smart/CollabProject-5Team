# 카메라 조작, 경계 제한

## 설정
- 카메라 컴포넌트 : Orthographic모드에 CameraManager.cs를 부착
- 필수 패키지
  - R3, DOTween

## 구현한 로직
1. 반응형 입력 루프(R3 활용)
    - R3를 사용한 이유:
     - 유니티의 Update()에서 같은 로직을 구현하려면 너무 많은 조건문이 사용될 것이기 때문에 코드 가독성과 유지보수성을 그리고 Where절을 통해 조건을 걸어 필요할 때만 로직을 수행해 불필요한 메모리 낭비를 하지 않도록 R3를 도입
  
   - `Start()`시점에 `this.UpdateAsObservable()`로 매 프레임 입력 상태를 관찰
   - UI오픈 상태 플래그`!IsUIOpen.Value`를 `.Where()` 조건으로 필터링하여, UI창이 열려있지 않을 때만 카메라 조작 연산을 하여 CPU를 낭비하지 않도록함
   - 오브젝트 파괴 시 `AddTo()`로 구독을 등록해 두고, `OnDestroy()`에서 `CompositeDisposable`로 구독 해제함으로써 메모리 누수 차단

2. 멀티 터치(에디터 마우스 휠)로 줌 기능
   - 2개의 터치가 감지되었을 때 중심점`midPoint`과 픽셀 거리 `Vector2.Distance`를 계산
   - `ZoomToLocation()`에서 줌 실행 전/후 월드 좌표 차이를 계산하여 해당 지점 줌인/아웃
   - 인스펙터에서 설정한 최소`_minSize`, 최대`_maxSize` 범위 안에서만 줌인/아웃 가능하도록 `Mathf.Clamp`로 처리
  
3. 한 손 드래그 및 관성 처리(DOTween 연동)
   - DOTween을 사용한 이유:
     - Lerp나 SmoothDamp로 카메라 움직임의 관성을 구현하려면 Update() 내에서 가속도 수한 계산을 매 프레임 돌려야하고 코드가 지저분해짐 -> DOTween의 `Ease.OutCubic`으로 간편하게 구현
     - `GetClampedCameraPosition()`에서 계산된 안전한 좌표만 `DOMove`에 전달하여 이동중인 카메라가 맵밖으로 나가지 않도록 함
  
   - 드래그 이동 : 레이캐스트가 레이어에 부딪히는 대신 가상의 수평 평면 `Plane(Vector3.up, Vector3.zero)`을 생성하고 `GetTouchWorldPosition()`을 통해 터치 지점을 3D월드 좌표로 변환 화면의 2D 픽셀 좌표 대신 3D 월드 좌표의 변화량을 구해 카메라 위치에서 빼줌으로써(`-=`), 카메라의 줌 배율과 상관없이 손가락 끝에 화면이 붙어 움직이는 자연스러운 드래그 감도를 구현
   - 터치가 시작 되면 `TouchPhase.Began`에 `IsPointerOverUIObject()`를 실행해 터치 시작점이 UI위라면 `_isCameraDragValid = false`로 잠금
   - 손가락을 떼는 순간 (`TouchPhase.Ended, Canceled`) 최종 프레임의 이동 속도 벡터(`_drag`) 가 유효하다면, DOTween의 `DOMove`를 이용해 가던 방향으로 미끄러지듯 감속, 정지(`Ease.OutCubic`) 새로운 터치가 시작되면 작동중인 관성 트윈을 `Kill()`함

4. 45도 회전된 마름모꼴 맵의 경계 제한 (`ClampCameraPosition()`)
   - 비스듬한 카메라 각도로 인해 발생하는 카메라 위치와 화면 중심 조준점 간의 불일치를 `targetPos - currentLookAtPos`로 계산
   - 가상의 레이저를 카메라 이동 전 발사해 미리 거리를 계산하고 카메라를 이동해 Jittering방지
   - 대각선 화면 마진 계산: 카메라의 반듯한 화면(가로/세로 반폭)을 45도 누워있는 마름모 벽면에 대응시키기 위해, 45도 직각삼각형의 대각선 비율인 sin(45°) ≒ 0.7f를 곱하여 '기울어진 벽 전용 카메라 마진(scaleX, scaleZ)'을 구함.
   - 줌 배율별 가변 한계선 설정: 맵의 원래 크기(`_diamondWidth, _diamondLength`)에서 카메라 화면 마진을 빼서 움직일 수 있는 범위(`clampWidth, clampHeight`)를 정하고 이때 과도한 줌아웃으로 계산값이 음수(-)가 되면 `Mathf.Max(0, ...)`에 의해 0으로 고정되어 카메라가 정중앙에 고정(드래그 불가)
   - 45도 좌표계 변환 및 가두기: 45도 비스듬한 마름모 벽은 유니티의 일반 X, Z 축 정렬만으로는 가둘 수 없으므로, 카메라 좌표의 X와 Z를 서로 더하고 뺀 값(sumXZ, diffXZ)을 이용함. 이는 계산하는 프레임 동안 잠시 45도 회전시켜 '반듯한 직사각형'으로 만드는 수학적 기법, 반듯해진 상태에서 `Mathf.Clamp`로 카메라 위치를 안전하게 가둠.
   - 원래 좌표계 복구: 가두기 연산이 끝난 가상의 회전 축들을 다시 연립방정식(더한 값과 뺀 값을 서로 더하거나 빼서 반으로 자르는 공식)으로 풀어서 유니티의 원래 3D 월드 좌표(pos.x, pos.z)로 복구함. 이 경계 체크는 일반 드래그, 줌뿐만 아니라 DOTween의 관성 이동 중에도 `OnUpdate`로 매 프레임 실행되어 어떤 조작 중에도 카메라가 맵 밖 비추지 못하도록함.

## 변수들(숫자는 테스트하면서 얻은 기본 설정 값)
- `_screenMoveSpeed` : 모바일 터치 드래그 시 카메라 화면 이동 속도(`1`)
- `_zoomSpeed` : 두 손가락으로 줌 실행 시 변화 속도(`0.05`)
- `_inertiaduration` : 드래그 후 손을 뗐을 때 미끄러지는 관성 애니메이션 지속 시간(`0.5`)
- `_defaultSize` : 게임 시작 시 카메라의 기본 Orthgraphic Size 값(`13`)
- `_minSize` : 카메라의 최대 줌인(`5`)
- `_maxSize` : 카메라의 최대 줌아웃(`13`)
- `_diamondWidth` : 마름모꼴 맵 중심0,0에서 오른쪽 꼭지점까지의 월드 거리(`10`)
- `_diamondLength` : 마름모꼴 맵 중심 0,0에서 위쪽 꼭지점까지의 월드 거리(`10`)
