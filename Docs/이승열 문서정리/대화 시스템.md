## DialogueManager.cs

대화 흐름 제어 싱글톤

```csharp
// NPCInteract.OnInteract() state==1에서 호출
public void StartDialogueById(Employee emp)

// 팝업 선택지 버튼에서 호출 (index: 0=선택지1, 1=선택지2)
public void SubmitChoice(int selectedIndex)

// 팝업 터치(확인) 시 호출 - is_choice=FALSE 노드
public void AdvanceDialogue()
```

**상태 판정 기준**
```
fatigue <= 50 AND desire >= 50 → Normal
fatigue > 50  AND desire < 50  → Critical
그 외                           → Caution
```

**내부 흐름**
`StartDialogueById` → 상태 판정 → `GetPoolEntry` → `ShowNode` → `NotifyDialogueReady`
→ `EndDialogue` → 효과 적용 → `CompleteSpecialDialogue` → `NotifyDialogueEnded`

### _EmployeeManager.cs

```csharp
// Start(): OnStatChangeRequested 구독 → 스탯 반영
Dialogue.DialogueEvents.OnStatChangeRequested
    .Subscribe(delta =>
    {
        Employee emp = _haveEmployees.haveEmployeeList
            .Find(e => e.so.id == delta.employeeId);
        data.desire  += delta.desireDelta;
        data.fatigue += delta.fatigueDelta;
        data.loyalty += delta.loyaltyDelta;
        emp.MutableData = data;
    })

├─ PlayerDialogueView   → 유저 대사 표시
├─ EmployeeDialogueView → 직원 대사 표시
├─ ChoiceItemView 01    → 선택지 버튼
└─ ChoiceItemView 02    → 선택지 버튼
```

### DialoguePresenter.cs

`OnDialogueReady` / `OnDialogueEnded` 구독 → View 바인딩. 터치/입력 처리는 외부 담당

```csharp
// 인스펙터 연결 (씬에 미리 배치된 오브젝트)
[SerializeField] private PlayerDialogueView   _playerView;
[SerializeField] private EmployeeDialogueView _employeeView;
[SerializeField] private ChoiceItemView       _choiceItem01;
[SerializeField] private ChoiceItemView       _choiceItem02;
```

**씬 배치**
```
Canvas (Active)
└─ DialoguePresenter (Active)
├─ PlayerDialogueView   (비활성 시작)
├─ EmployeeDialogueView (비활성 시작)
├─ ChoiceItem01         (비활성 시작)
└─ ChoiceItem02         (비활성 시작)
```

**흐름**
```
OnDialogueReady(payload)
→ isUser=true  → PlayerDialogueView.Bind()
→ isUser=false → EmployeeDialogueView.Bind() (상태별 초상화 선택)
→ isChoice=true → 타이핑 완료 후 ChoiceItem 표시 + Next 버튼 숨김

OnChoiceSelected(index) → HideChoices + Next 버튼 복구 + SubmitChoice(index)
OnDialogueEnded → 전체 비활성 + CloseInteractionUI
```
