## DialogueData.cs

열거형 및 구조체 정의 파일

```csharp
public enum EmployeeDialogueState { Normal, Caution, Critical }

public struct StatDelta
{
    public int employeeId;
    public int desireDelta;
    public int fatigueDelta;
    public int loyaltyDelta;
}

public struct DialogueStartPayload
{
    public int   employeeId;
    public EmployeeDialogueState state;
    public string text;
    public bool  isChoice;
    public bool  isUser;
    public string choice01;
    public string choice02;
}
```

## DialogueManager.cs

대화 흐름 제어 싱글톤

```csharp
// NPCInteract.OnInteract() state==1에서 호출
public void StartDialogueById(Employee emp)

// 팝업 선택지 버튼에서 호출 (index: 0=선택지1, 1=선택지2)
public void SubmitChoice(int selectedIndex)

// 팝업 터치(확인) 시 호출 - is_choice=FALSE 노드
public void AdvanceDialogue()
```

**상태 판정 기준**
```
fatigue <= 50 AND desire >= 50 → Normal
fatigue > 50  AND desire < 50  → Critical
그 외                           → Caution
```

**내부 흐름**
`StartDialogueById` → 상태 판정 → `GetPoolEntry` → `ShowNode` → `NotifyDialogueReady`
→ `EndDialogue` → 효과 적용 → `CompleteSpecialDialogue` → `NotifyDialogueEnded`

## TEST_DialoguePopupUI.cs

대화 팝업 테스트용 UI

**인스펙터 연결 필요**

| 슬롯 | 대상 |
|---|---|
| `_dialogueText` | 대사 TMP |
| `_choiceBtn01/02` | 선택지 버튼 |
| `_choiceText01/02` | 선택지 텍스트 TMP |
| `_portrait` | 초상화 Image |

**동작**
- `OnDialogueReady` 구독 → 팝업 표시 + 타이핑
- `OnDialogueEnded` 구독 → 팝업 닫기 + 플레이어 이동 복구
- 터치 → 타이핑 중: 스킵 / 완료 후: `AdvanceDialogue()`
- 선택지 클릭 → `SubmitChoice(index)`

**초상화 로직**
- `isUser=true` → 숨김
- `isUser=false` → state에 따라 `iconNormal` / `iconCaution` / `iconCritical`

### NPCInteract.cs

```csharp
// Awake
emp = GetComponent<Employee>();
emp.Init();

// Start
_EmployeeManager.Instance.haveEmployees.AddEmployee(emp);

// OnInteract - state==0: 이동 복구
GameManager.Instance.player?.CloseInteractionUI(); return;

// OnInteract - state==1: 대화 시작
Dialogue.DialogueManager.Instance.StartDialogueById(emp);
DateTimeManager.Instance.MarkTalkedThisWeek(emp); return;

// OnInteract - state==2: See Ya
dialogueText.text = $"{npcName}: See Ya (Done)";
```

### _EmployeeManager.cs

```csharp
// Start(): OnStatChangeRequested 구독 → 스탯 반영
Dialogue.DialogueEvents.OnStatChangeRequested
    .Subscribe(delta =>
    {
        Employee emp = _haveEmployees.haveEmployeeList
            .Find(e => e.so.id == delta.employeeId);
        data.desire  += delta.desireDelta;
        data.fatigue += delta.fatigueDelta;
        data.loyalty += delta.loyaltyDelta;
        emp.MutableData = data;
    })
```
