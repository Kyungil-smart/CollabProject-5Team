## 3. 이전 KPT 회고
### Keep
- 문서정리: 작업후 내용을 정리하여 문서로 남기는 작업이 도움이 됨
### 회고
- 문서로 남기는 작업을 이전에 비해 덜 하게 되었다
	- 기능 구현이 막바지 작업이였고 버그 수정작업이 많아서 소흘히 하게 됨 
	- OBT 이후에는 문서 작업을 소흘히 하지 않도록 노력하자 

### Problem
- 게임씬에 집중된 기능으로 병합작업의 곤란: 프리펩화 등으로 해결하려 했으나, 외부참조가 많아서 해결이 힘든 구조
- 데이터 관리의 어려움: 데이터가 많아지면서 관리가 어려워질 것으로 예상됨
- 기획서 해석의 어려움: 기획서의 모호한 부분에 대해서 소통하고 구현하는 단계에 시간이 많이 소요될 것으로 예상됨
- 객체 관리의 어려움: 직원 교용/해고와 회사 규모에 따른 객체 관리가 어려울 것으로 예상됨
### 회고
- 프리펩화의 외부참조 문제는 코드 구조 개선으로 해결하려는 노력을 하였다
- 데이터 시트 리뷰를 통해 데이터 형태를 기획자와 함께 논의하고 개선하려는 노력을 하였다
- 객체가 많아져서 렉이 발생하는 문제가 있었지만 빛 굽기등 최적화 가능한 것들을 산출하여 정리하였다

### Try
- 기획반과 원할한 소통: 구두로 하는 소통은 휘발성이 강하다, 중요한 내용은 문서로도 남겨서 원할한 소통을 해보자 (+ 회고록 확인)
- 객체 참조할때 인스펙터로 하는 씬 외부참조를 줄이고 파일시스템 기반 참조를 활용하자 (추후 리펙토링 예정) 
### 회고
- 기획자와 소통을 끝임없이 진행하여서 한번에 해결하지 못한 문제를 여러번에 걸쳐서 해결하려는 노력을 하였다

## 기타 의논 사항
- QA와 벨린싱 작업이 급한 상황이라 이부분은 기획자분들에게도 함께 의논하기로 하였다
- 장르와 게임 방향성을 확고하게 의논하도록 돕고, 강점을 살리는 기능에 집중해야 한다는 의견이 있었다
